## Решения

В данных заметила 4 состояния: предстоящие, завершенные, отложенные, лайв
Для прямой трансляции, которая идет сейчас сделала отдельную кнопку фильтра, так как считаю, что пользователям надо видеть такие матчи отдельно, не искать их в других фильтрах, live наиболее приоритетное состояние

Особенности данных: 
- Минуты есть только у live матчей, поэтому при рендере делала проверку на поле minutes в типе Match, а само поле сделала необязательным.
- У отложенных матчей дата неизвестна, поэтому вместо числа и времени отображается текст "дата неизвестна", а само поле startsAt может быть не только строкой, но и пустым типом null
- Поля у противостоящих команд совпадают, поэтому у обеих команд тип Team
- Там, где пустое значение счета оставила пустоту в карточке

## Баги из части 2

1. Звёздочки: использовался неверный метод массива (необходимо было проверять наличие id в массие favourites). Для этого использовала метод includes для проверки наличия в избранных. Также исправила ф-ю toggle, она не учитывала новый уже измененный массив. Поэтому в новой ф-ии toggle из ранее имеющегося массива избранных удаляется или добавлется новая карточка по id.
2. «Обновлено N сек назад»: не учитывается изменение since, всегда берется сотсояние seconds = 0 и именно к нему прибавляется 1, а не к предыдущему состоянияю. Для исправления в useEffect создала ф-ю для рассчета точной разницы в секундах.
